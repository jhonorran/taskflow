# TaskFlow 📝

Um sistema de tarefas simples e interativo feito com HTML, CSS e JavaScript.

## 🚀 Funcionalidades

- Adicionar tarefas
- Categorias (Estudos, Trabalho, Academia, Pessoal)
- Prioridades
- Horário para tarefas
- Filtro por status (Concluídas / Pendentes)
- Filtro por categoria
- Calendário semanal
- Marcar tarefas como concluídas
- Barra de progresso
- Tarefas recorrentes (diárias)
- Salvamento automático no navegador (localStorage)

## 💻 Tecnologias usadas

- HTML5
- CSS3
- JavaScript
